Install with Deadlock Mod Manager

One-click installs work with the DMM 2.4 nightly. For DMM 2.3 and other managers, use one-click install on GameBanana.

Install without a mod manager
Download ZIP VPK only
  1. Close Deadlock. In Steam, right-click Deadlock → Manage → Browse local files.
  2. Inside game/citadel, create addons/settings-config. Put the extracted VPK there and name it pak01_dir.vpk.
  3. Back up game/citadel/gameinfo.gi, then open it in a text editor. Under FileSystem → SearchPaths, add these entries above Write citadel. Skip any entry already present.Game citadel/addons/settings-config
    Mod citadel
  4. Save, launch from Steam, and open Esc → Settings Config. If a game update resets the search paths, restore those entries.

Community configs

Publish in Deadlock

  1. Open Esc → Settings Config in the hideout.
  2. Choose Upload config to capture and name your settings. Steam verifies your account the first time.
  3. Select Publish config.
